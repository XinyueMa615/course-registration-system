# 课程注册系统

这是从原数据库课程项目整理出的改造版本。原项目保留不动，本目录用于软件工程课程设计。

## 当前已有功能

- 学生、教师和管理员入口
- 学生选课、退课、课表和成绩单
- 先修课与上课时间冲突检查
- 教师查看教学任务、学生名单和录入成绩
- 管理员维护课程、教学班、学生和教师

## 与课程设计题目的主要差距

- 主选 4 门与备选 2 门
- 教师自主选择符合资格的任教课程
- 全局关闭注册、少于 3 人取消和备选课补位
- 课程目录只读接口与计费系统模拟
- 等级制成绩 A/B/C/D/F/I
- 完整登录会话、密码加密与接口权限控制
- 可重复执行的数据库初始化脚本和正式自动化测试

## 本地启动

1. 按照 [`database/README.md`](database/README.md) 建立数据库和演示数据。
2. 复制 `.env.example` 为 `.env`，填写本机数据库配置。
3. 创建 Python 虚拟环境并安装依赖：

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r scripts/requirements.txt
   ```

4. 运行：

   ```bash
   python run.py
   ```

5. 浏览器访问 `http://127.0.0.1:8000/`。

后端接口文档位于 `http://127.0.0.1:8000/docs`，健康检查位于
`http://127.0.0.1:8000/health`。

## 安全说明

- `.env` 不得提交到 Git。
- 原项目曾把数据库管理员密码和用户密码直接写在代码里，应立即更换数据库密码。
- 当前登录接口仍兼容旧数据库的明文密码，后续必须迁移到密码哈希并加入真正的会话鉴权。
- `scripts` 中原有的大量一次性查库、改表和调试脚本只保留在本地参考，已通过 `.gitignore` 排除；新功能不得继续采用这种方式维护数据库。
